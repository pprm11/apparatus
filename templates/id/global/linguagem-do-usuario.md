# Linguagem do usuário (nível id)

Versão: v0.1, DD/MM/AAAA. Como esta pessoa usa as palavras. Regras de uso e termos gerais no superego;
termos do time no collective; termos da empresa no ego.

## Colisões (mesma palavra, coisas diferentes)

| Palavra | Sentidos | Termo padrão |
|---|---|---|
| git | o GitHub, quando dito sozinho · o comando (exemplo) | **GitHub** · **git** |

## Termos padrão
- **modelo bom**: o nível topo do harness (exemplo; diga qual).
- **cobrança**: o agente apontar o que a pessoa fez diferente do combinado (exemplo).

## Como interpretar pedidos
- Aprovações: "aprovado", "pode seguir" (exemplo). Valem só para o que foi proposto na mensagem
  anterior; nunca autorizam merge, push, delete ou ação irreversível nova.
- **análise profunda**: ler tudo, com teto declarado de modelos e subagentes (exemplo).
- Edite este glossário só depois do sim da pessoa, e suba a versão.
